# Citing gdrift

If you use gdrift in your research, please cite it. A Zenodo DOI is minted automatically for each release.

## BibTeX

```bibtex
@software{ghelichkhan_gdrift,
  author       = {Ghelichkhan, Sia},
  title        = {gdrift: Geodynamics Data Reformatting and Integration Facilitation Toolkit},
  url          = {https://github.com/g-adopt/g-drift},
  license      = {MIT}
}
```

!!! note "Zenodo DOI"
    After the first tagged release, a version-specific DOI and a concept DOI (always pointing to the latest version) will be available from [Zenodo](https://zenodo.org). We recommend citing the concept DOI so that readers are always directed to the most recent version. This section will be updated with the DOI badge once the first release is published.
